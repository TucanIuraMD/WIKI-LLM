# ReadmeMD

Приложение для **чтения и редактирования Markdown-файлов** напрямую во внешнем
Obsidian Vault.

ReadmeMD **не является хранилищем документов**: никаких копий Markdown внутри
проекта не создаётся. Источник документов — внешний Vault, путь к которому
задаётся конфигурацией (`VAULT_DIR` в `.env`).

## Возможности

- 📁 Дерево каталогов Vault (вложенные папки, кириллица, пробелы и спецсимволы в именах)
- 🔍 Мгновенный полнотекстовый поиск по содержимому Vault (Ctrl+K)
- 🕸️ Граф связей между документами по `[[wikilinks]]` (как в Obsidian)
- 📝 Front matter (`title`, `icon`, `tags`) вместо имени файла
- ✏️ Редактирование в браузере (Monaco Editor) с автосохранением
- 💾 Сохранение изменений **напрямую в Vault** (PUT `/api/page/<path>`)
- 📤 Drag & drop загрузка новых `.md` файлов
- 🔗 Обратные ссылки («что ссылается на этот документ»)
- 🖍️ Подсветка кода (highlight.js), таблицы, чек-листы, Mermaid, KaTeX
- 🧭 Автоматическое оглавление (TOC), хлебные крошки
- ⭐ Избранное и 🕘 недавно открытые (localStorage)
- 🎨 Смена иконки папки (сохраняется в `<папка>/.folder.json` внутри Vault)
- 📱 Адаптивный дизайн, светлая/тёмная тема

## Требования

- Python 3.9+
- Доступный каталог Obsidian Vault (существующий, с правами на чтение/запись)

## Установка и запуск

```bash
# 1. зависимости
pip install -r requirements.txt

# 2. конфигурация (.env) — укажите путь к реальному Vault
cp .env.example .env   # или отредактируйте существующий .env

# 3. запуск
python app.py
```

Сайт будет доступен на `http://<HOST>:<PORT>` (по умолчанию `0.0.0.0:5000`,
то есть `http://192.168.80.22:5000` при размещении на этом хосте).

## Конфигурация (`.env`)

```ini
# Путь к внешнему Obsidian Vault — источник документов ReadmeMD
VAULT_DIR=/opt/ai-stack/obsidian-vault

# HTTP-сервер
HOST=0.0.0.0
PORT=5000

# Отладочный режим Flask
DEBUG=0
```

`VAULT_DIR` — единственное место, где задаётся расположение Vault. Путь не
зашит в код. Если `VAULT_DIR` не задан — приложение не запустится с явной
ошибкой. Если каталог не существует — приложение запустится, но дерево будет
пустым, а чтение вернёт 404 (Vault не создаётся автоматически).

## Как определяются пути и безопасность

Все операции работают только внутри `VAULT_DIR`:

- Отклоняются абсолютные пути, `..` (path traversal), NUL-байты.
- `resolve()` раскрывает симлинки: любой путь, ведущий через симлинк за
  пределы Vault, отклоняется (HTTP 400).
- Симлинки-каталоги и симлинки-файлы за пределы Vault пропускаются при
  построении дерева и поиске.
- Запись разрешена только в `.md`-файлы; родительский каталог проверяется
  на принадлежность Vault.
- Загрузка файлов: имя очищается через `basename`, целевой каталог
  проверяется, допустимы только `.md`.

## Структура проекта

```
ReadmeMD/
├── app.py                 # Flask backend + API
├── requirements.txt       # Flask, PyYAML, python-dotenv
├── .env                   # конфигурация (VAULT_DIR, HOST, PORT)
├── templates/
│   └── index.html         # одностраничный интерфейс
└── static/
    ├── css/style.css
    └── js/app.js
```

Отдельного хранилища документов в проекте **нет** — `docs/` удалено.

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/` | веб-интерфейс |
| GET | `/api/tree` | дерево каталогов Vault |
| GET/PUT | `/api/folder-icon?path=<папка>` | получить / установить иконку папки |
| GET | `/api/page/<path>` | содержимое документа + обратные ссылки |
| PUT | `/api/page/<path>` | сохранить документ (запись в Vault) |
| DELETE | `/api/page/<path>` | удалить документ |
| GET | `/api/search?q=...` | полнотекстовый поиск |
| GET | `/api/graph` | узлы и рёбра графа связей |
| POST | `/api/upload` | загрузка нового `.md` файла (multipart, поле `file`, `folder`) |

## История версий

Система снимков `.versions/` **удалена**. ReadmeMD пишет прямо в Vault без
создания локальных копий; будущим механизмом истории изменений станет Git
(на этом этапе Git-интеграция не реализована).

## Примечания

- Front matter: если `title`/`icon`/`tags` не указаны, заголовок берётся из имени файла.
- Wikilinks `[[Название]]` и `[[Путь/Файл|Отображаемый текст]]` резолвятся в
  переходы, рёбра графа и обратные ссылки.
- Однопользовательский внутренний инструмент, авторизации нет — не выставляйте
  порт наружу без дополнительной защиты (например, обратный прокси с basic-auth).
