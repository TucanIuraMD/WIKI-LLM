# ReadmeMD — статус проекта

## 1. Что было обнаружено в старой реализации

Исходный код (`app.py` до переработки) содержал:

- **Жёсткую привязку к `docs/`**: `DOCS_DIR = BASE_DIR / "docs"` — собственное
  хранилище документов внутри проекта. Документы копировались/создавались
  в этом каталоге.
- **Систему версий `.versions/`**: снимки файлов при каждом сохранении
  (до 50 штук на документ). Запись производилась в каталог `.versions/`
  рядом с проектом, создавая дубликаты содержимого.
- **`safe_path()`**: проверял принадлежность к `DOCS_DIR`, но не учитывал
  симлинки, ведущие наружу: `resolve()` выполнялся, но явной проверки
  на `is_within_vault` не было, и `parents` не раскрывает симлинки
  вышестоящих компонентов.
- **JSON_AS_ASCII**: использовал устаревший `app.config["JSON_AS_ASCII"]`
  (Flask 2.x → удалён в Flask 3.x).
- **Нет `.env`**: HOST, PORT, VAULT_DIR были неконфигурируемы.
- **Frontend**: бренд «Тест — база знаний», кнопка истории версий, модалка
  и JS-обработчики для версий.

## 2. Что изменено

1. **Архитектура хранения**: удалена привязка к `docs/`. Источник документов —
   внешний Vault, путь задаётся через `VAULT_DIR` в `.env`.
2. **Система версий `.versions/`**: полностью удалена (backend + frontend).
   Будущий механизм истории — Git.
3. **Конфигурация**: добавлен `.env` (VAULT_DIR, HOST, PORT, DEBUG).
   `load_dotenv()` загружает его при старте.
4. **Безопасность путей**: новый `safe_vault_path()` с многоуровневой защитой
   (отклонение `..`, абсолютных путей, NUL-байтов; раскрытие симлинков через
   resolve() + проверка is_within_vault).
5. **Безопасный обход Vault**: функция `_safe_walk()` на основе `os.walk`
   (followlinks=False) пропускает симлинки-каталоги, файлы-симлинки за
   пределами Vault, скрытые файлы. Используется в `iter_all_docs()`.
6. **Построение дерева**: `build_tree()` проверяет каждый entry через
   `is_within_vault()` и пропускает симлинки-каталоги.
7. **JSON**: `app.json.ensure_ascii = False` (Flask 3.x).
8. **Frontend**: бренд сменён на «ReadmeMD», кнопка «История версий» и
   модалка удалены, хлебные крошки и welcome-текст обновлены.
9. **Очищен проект**: удалены пустые `docs/`, `__pycache__`, `символы/`.
10. **Добавлен `.env.example`** для справки.

## 4. Как теперь определяется VAULT_DIR

В порядке приоритета:

1. Переменная окружения `VAULT_DIR` (если задана — имеет приоритет).
2. Файл `.env` (загружается `load_dotenv()` — не перезаписывает уже заданные
   переменные).

Если `VAULT_DIR` не задан — `_resolve_vault_dir()` бросает `RuntimeError`
с сообщением: «укажите VAULT_DIR в .env или в окружении».

Если каталог не существует — приложение запускается с предупреждением,
дерево будет пустым, чтение вернёт 404.

## 5. Как реализована защита от выхода за пределы Vault

**`safe_vault_path(rel_path)`:**

1. Отбрасывает пустые, NUL-байты, абсолютные пути.
2. `os.path.normpath()` нормализует `..`; если после нормализации путь
   содержит `../` — отклонение.
3. Строится путь `VAULT_DIR / normalized`, раскрывается через `resolve()`
   (раскрытие симлинков).
4. `is_within_vault()`: проверяет, что `resolve()`-путь является потомком
   или равен `VAULT_DIR.resolve()`. Если симлинк ведёт наружу — отклонение.

**Обход Vault (`_safe_walk`, `build_tree`):**

- `os.walk(followlinks=False)` — симлинки-каталоги не обходятся.
- Каждый entry проверяется `is_within_vault()`.
- Симлинки-каталоги в `build_tree` пропускаются (не показываются в дереве).

**Запись/загрузка:**

- Допустимы только `.md`-файлы.
- Родительский каталог проверяется `is_within_vault()` перед `mkdir`/записью.
- `upload` использует `os.path.basename()` для изоляции имени файла.

## 7. Результаты тестов

Все тесты пройдены. Приложение корректно:

- Отдаёт дерево Vault (включая кириллические имена и пробелы).
- Читает документы с кириллицей, пробелами, вложенными путями.
- Сохраняет изменения **напрямую в Vault** (проверено md5 файла).
- Выполняет поиск по содержимому (кириллица, латиница).
- Строит граф связей на основе `[[wikilinks]]`.
- Принимает загрузку `.md` файлов (ASCII и кириллица).
- Отклоняет попытки выйти за пределы Vault (path traversal, абсолютные пути,
  симлинки наружу).
- Отклоняет загрузку не-`.md` файлов.
