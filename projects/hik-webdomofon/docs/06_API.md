# API

## Назначение

Backend предоставляет REST API и WebSocket API для работы с системой.

Бизнес-логика находится только на Backend.

---

# Авторизация

Все защищённые методы требуют JWT-токен.

Публичные методы явно отмечаются в документации.

---

# Разделы API

## Authentication

Авторизация пользователей.

---

## Users

Управление пользователями.

---

## Door

Управление дверью.

Основные операции:

- открытие двери;
- получение состояния.

---

## Video

Получение параметров видеопотока.

Backend не транслирует видео, а предоставляет конфигурацию клиента.

---

## Audio

Управление голосовой связью.

Используется WebSocket.

Backend взаимодействует с HCNetSDK.

---

## Events

Получение событий через WebSocket.

Используется для:

- состояния вызова;
- открытия двери;
- изменений системы;
- уведомлений.

---

## Settings

Получение и изменение настроек системы.

Доступно только администраторам.

---

# WebSocket

## /ws/audio

Двусторонняя передача аудио.

Формат:

- G.711 μ-law
- 20 ms frame

---

## /events

Передача событий системы.

Используется Mini App.

---

# Ошибки

Все ошибки возвращаются в формате:

```json
{
    "success": false,
    "error": {
        "code": "...",
        "message": "..."
    }
}
```

---

# Версионирование

При несовместимых изменениях используется новая версия API.

Например:

/api/v2/
```
