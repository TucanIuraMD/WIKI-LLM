# Deployment

## Назначение

Документ описывает процесс установки, настройки и запуска проекта.

---

# Требования

## Операционная система

Поддерживаются:

- Linux (рекомендуется)
- Windows

---

## Программное обеспечение

Необходимо установить:

- Python
- FFmpeg
- go2rtc
- HCNetSDK
- Git

---

# Структура проекта

```
project/

backend/
frontend/
telegram/
go2rtc/

config/
logs/
data/
docs/
```

---

# Переменные окружения

Основные параметры конфигурации задаются через `.env`.

Например:

- адрес Backend;
- JWT Secret;
- параметры Telegram;
- параметры камеры;
- параметры go2rtc.

Секретные данные не должны храниться в исходном коде.

---

# Настройка камеры

Необходимо указать:

- IP-адрес;
- порт;
- имя пользователя;
- пароль.

Используется HCNetSDK.

---

# Настройка go2rtc

Необходимо:

- указать RTSP-источник;
- настроить WebRTC;
- настроить HLS.

После запуска необходимо проверить доступность видеопотока.

---

# Запуск Backend

Backend запускается после:

- загрузки конфигурации;
- подключения к базе данных;
- инициализации HCNetSDK;
- регистрации маршрутов API.

---

# Запуск Telegram Bot

Перед запуском необходимо:

- указать токен бота;
- настроить Webhook или Polling;
- проверить связь с Backend.

---

# Запуск Mini App

Frontend собирается отдельно.

После сборки размещается на Web Server.

Backend должен знать URL Mini App.

---

# Проверка системы

После запуска необходимо проверить:

- авторизацию;
- видео;
- голосовую связь;
- открытие двери;
- работу уведомлений.

---

# Обновление

При обновлении рекомендуется:

1. создать резервную копию базы данных;
2. сохранить файл конфигурации;
3. обновить исходный код;
4. установить новые зависимости;
5. выполнить миграции (если имеются);
6. перезапустить сервисы.

---

# Резервное копирование

Рекомендуется регулярно сохранять:

- базу данных;
- файл конфигурации;
- пользовательские данные;
- журналы (при необходимости).

---

# Журналирование

Во время эксплуатации рекомендуется контролировать:

- Backend;
- Telegram Bot;
- go2rtc;
- системные журналы.

---

# Возможные проблемы

При возникновении неисправностей рекомендуется проверить:

- доступность камеры;
- доступность go2rtc;
- параметры сети;
- корректность конфигурации;
- срок действия токенов.

---

# Принципы эксплуатации

Во время работы системы:

- не выполнять повторную авторизацию HCNetSDK без необходимости;
- не изменять конфигурацию "на лету" без проверки;
- использовать только поддерживаемые версии зависимостей.
