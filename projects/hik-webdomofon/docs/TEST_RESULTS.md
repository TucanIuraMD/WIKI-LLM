## 9. Известные ограничения

1. **RTSP timeout** — камера продолжает разрывать RTSP-соединения (проблема сети/камеры)
2. **Telegram WebView** — ограничения на фоновые процессы остаются
3. **iOS Safari** — MSE через ManagedMediaSource может работать иначе
4. **WebRTC ICE** — STUN-серверы (Cloudflare, Google) требуют доступа в интернет
