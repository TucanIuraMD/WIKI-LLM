# Known Issues

## Назначение

Документ содержит перечень известных проблем проекта.

В него включаются только подтверждённые ошибки.

После исправления запись не удаляется, а переводится в статус **Fixed**.

---

# Статусы

| Статус | Описание |
|---------|----------|
| Open | Ошибка подтверждена |
| In Progress | Исправление в работе |
| Fixed | Исправлена |
| Won't Fix | Исправление не планируется |

---

# Приоритеты

| Приоритет | Описание |
|------------|----------|
| Critical | Система неработоспособна |
| High | Серьёзное ограничение функциональности |
| Medium | Ошибка влияет на работу, но есть обходной путь |
| Low | Незначительная проблема |
