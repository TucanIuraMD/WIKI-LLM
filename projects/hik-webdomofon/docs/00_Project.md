# Web Doorphone

## О проекте

Web Doorphone — это современная система управления домофоном на базе камеры Hikvision с веб-интерфейсом и интеграцией с Telegram.

Проект создаётся как альтернатива классическим SIP-домофонам с упором на простоту, безопасность и удалённое управление.

---

# Цели проекта

- Просмотр видео в режиме реального времени.
- Двусторонняя аудиосвязь (Push-To-Talk).
- Удалённое открытие двери.
- Управление пользователями.
- Временные и одноразовые приглашения.
- История посещений.
- Полный журнал аудита.

---

# Основные возможности

### Видеонаблюдение

- WebRTC
- HLS
- go2rtc

### Аудио

- Push-To-Talk
- HCNetSDK
- G.711 μ-law

### Управление доступом

- открытие двери;
- пользователи;
- роли;
- права;
- приглашения.

### Telegram

- Bot
- Mini App
- уведомления
- команды
- быстрые действия

---

# Принципы проекта

Проект строится вокруг Telegram Mini App.

Telegram используется для:

- уведомлений;
- быстрых действий;
- приглашений.

Основной пользовательский интерфейс — Mini App.

---

# История

Вся история хранится внутри приложения.

Telegram не используется как журнал событий.

---

# Безопасность

Все действия пользователя:

- открытие двери;
- создание приглашения;
- изменение настроек;
- действия администратора;

фиксируются в журнале аудита.
