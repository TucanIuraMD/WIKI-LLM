# Plan: Telegram Bot + Web Doorphone Integration

## Architecture Overview

```
┌─────────────┐     ┌──────────────────┐     ┌─────────────┐
│  Telegram    │────▶│  hik-telegram-bot│────▶│   SQLite    │
│  Bot API     │     │  (new service)   │     │  users.db   │
└─────────────┘     └──────┬───────────┘     └─────────────┘
                           │ API calls
                    ┌──────▼───────────┐
                    │    hik-talk      │
                    │  (existing)      │
                    │  /ws/audio       │
                    │  /api/door/open  │
                    └──────┬───────────┘
                           │
                    ┌──────▼───────────┐     ┌─────────────┐
                    │    hik-web       │     │   go2rtc    │
                    │  (nginx/HTTPS)   │────▶│  video      │
                    │  doorphone.html  │     └─────────────┘
                    └──────────────────┘
```

## Components to Create/Modify

### 1. New Service: `hik-telegram-bot/`

**Files to create:**
- `hik-telegram-bot/Dockerfile` — Python 3.13-slim, pip install dependencies
- `hik-telegram-bot/requirements.txt` — python-telegram-bot, aiosqlite, fastapi, uvicorn
- `hik-telegram-bot/app/main.py` — FastAPI app with Telegram bot + API endpoints
- `hik-telegram-bot/app/bot.py` — Telegram bot logic (registration flow, WebApp sending)
- `hik-telegram-bot/app/database.py` — SQLite async wrapper (aiosqlite)
- `hik-telegram-bot/app/models.py` — Pydantic models for API

**Bot flow:**
1. User scans QR → opens `https://t.me/<bot_name>?start=<house_id>`
2. Bot receives `/start <house_id>` → checks SQLite for telegram_user_id
3. If not found → asks "Введите номер квартиры" → saves to DB → sends WebApp button
4. If found → immediately sends WebApp button (no re-registration)
5. WebApp button opens `https://<host>/doorphone.html?house=<house_id>&user=<telegram_user_id>`

**API endpoints (on hik-telegram-bot):**
- `GET /api/telegram/check?user_id=<int>` → `{registered: bool, apartment: int|null}`
- `GET /api/telegram/user?user_id=<int>` → `{user_id, apartment, house_id, created_at}`
- `POST /api/telegram/register` → body: `{user_id, apartment, house_id}` → saves to DB
- `POST /api/door/open` → body: `{user_id, house_id}` → calls hik-talk to open door

**Database schema (SQLite):**
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    telegram_user_id INTEGER UNIQUE NOT NULL,
    apartment INTEGER NOT NULL,
    house_id TEXT NOT NULL DEFAULT 'main',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE houses (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    go2rtc_stream TEXT,
    ws_audio_url TEXT,
    door_api_url TEXT
);
```

### 2. New HTML Page: `hik-web/doorphone.html`

**Full-screen doorphone interface with:**
- Video: iframe loading go2rtc `stream.html?src=camera&mode=webrtc,mse,mjpeg`
- PTT button: reuses logic from `ptt-camera.html` (connects to `/ws/audio`)
- Door open button: POST to `/api/door/open`
- Connection status indicator (WebSocket state)
- Microphone level meter
- Telegram WebApp integration (reads `initData` from `Telegram.WebApp.initDataUnsafe`)

**Styling:** Dark theme, modern minimal, adapted for mobile (Android/iPhone), safe-area-inset support

### 4. Modify: `docker-compose.yml`

Add `hik-telegram-bot` service:
```yaml
hik-telegram-bot:
  build:
    context: ./hik-telegram-bot
  container_name: hik-telegram-bot
  env_file:
    - .env
  ports:
    - "9001:9001"
  volumes:
    - bot-data:/app/data
  restart: unless-stopped
```

### 5. Modify: `.env`

Add:
```
TELEGRAM_BOT_TOKEN=<token from BotFather>
BOT_WEBAPP_URL=https://<host>/doorphone.html
HOUSE_ID=main
```

### 6. Modify: `hik-web/nginx.conf`

Add proxy rules:
```nginx
# Telegram bot API
location /api/telegram/ {
    proxy_pass http://hik-talk:9000/api/telegram/;
    # ... standard proxy headers
}

location /api/door/ {
    proxy_pass http://hik-talk:9000/api/door/;
    # ... standard proxy headers
}

# Doorphone page
location /doorphone.html {
    try_files /doorphone.html =404;
}
```

### 7. Modify: `hik-web/Dockerfile`

Add:
```dockerfile
COPY doorphone.html /usr/share/nginx/html/doorphone.html
```

## Verification

1. **Build:** `docker compose build --no-cache`
2. **Start:** `docker compose up -d`
3. **Bot test:** Open `https://t.me/<bot_name>?start=main` in Telegram
4. **Registration:** Enter apartment number → bot sends WebApp button
5. **WebApp:** Click button → doorphone.html opens with video + PTT
6. **PTT:** Hold button → audio sends to camera
7. **Door:** Click "Open door" → relay triggers
8. **Re-entry:** Scan QR again → bot recognizes user, no re-registration
